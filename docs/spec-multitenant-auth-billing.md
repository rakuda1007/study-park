## 1. 目的

Study Park に **メールアドレスによるログイン** を導入し、次のビジネス・技術構成を実現する。

1. **お試し（トライアル）** … クリエイター機能を最長2年・上限付きで無料体験
2. **スターター** … ¥980（1回）で期限なく継続利用（上限付き）
3. **月額サブスク（S/M/L）** … ストレージまたは問題数が上限に達した場合の容量アップ

同時に、**プラットフォーム管理者 / クリエイター / 学習者** の3ロールを定義し、学習者はクリエイターに紐づき、そのクリエイターが作成したコンテンツを利用できるようにする。

本仕様書は **実装手順・API・データモデル・課金ルール・公開方式** を固定する。

**用語**: UI・ドキュメントでは **「買い切り」とは呼ばない** → **「スターター」** を用いる。

## 3. ビジネスルール概要

### 3.1 商品構成

```
[無料]       九九・県庁（アカウント不要・永続無料）
[お試し]     クリエイター機能・最長2年・上限あり
[スターター] ¥980（1回）・期限なし・上限あり
[月額]       S / M / L（容量アップ・任意）
```

**課金単位**: 1 クリエイター = 1 ワークスペース

### 3.2 コンテンツ種別と課金


| 種別            | 例                              | 登録      | クリエイター機能         | 課金         |
| ------------- | ------------------------------ | ------- | ---------------- | ---------- |
| **無償・公式**     | 九九（`/kuku/`）、県庁所在地（`/kencho/`） | 不要      | 利用のみ（作成不可）       | なし         |
| **お試しクリエイター** | Firestore 管理のレッスン・クイズ          | アカウント必要 | 作成・編集・公開（上限内）    | お試し（最長2年）  |
| **スターター済み**   | 同上                             | 同上      | 同上（スターター枠内・期限なし） | スターター ¥980 |
| **月額契約中**     | 同上                             | 同上      | 同上（S/M/L 枠内）     | 月額 S/M/L   |


※ 九九・県庁は **ワークスペースに登録せず**、従来どおり `public/` 静的アプリとして無償提供する。

### 3.3 料金プラン（確定）

#### 早見表


| プラン        | ID        | 種別   | 価格（税込）       | 期間              | 問題数上限       | ストレージ上限    |
| ---------- | --------- | ---- | ------------ | --------------- | ----------- | ---------- |
| お試し（トライアル） | `trial`   | 無料   | ¥0           | **WS 作成から最長2年** | **80 問**    | **100 MB** |
| スターター      | `starter` | 1回払い | **¥980**     | **なし**          | **200 問**   | **100 MB** |
| S          | `s`       | 月額   | **¥480/月**   | 契約中             | **500 問**   | **1 GB**   |
| M          | `m`       | 月額   | **¥980/月**   | 契約中             | **1,000 問** | **5 GB**   |
| L          | `l`       | 月額   | **¥2,480/月** | 契約中             | **2,000 問** | **20 GB**  |


#### 上限の適用（2軸・OR）

次の **いずれか先に到達** で該当プランの上限として扱う。

- `storageBytesUsed > storageBytesLimit`
- `questionCount >= questionCountLimit`（新規追加時に検証）

**新規作成のゲート**

- 上限到達時: **新規問題の追加・新規画像アップロードを禁止**
- 既存公開コンテンツの **閲覧（学習）は原則継続**（[§10.4](#104-未払い解約お試し期限) 参照）

#### 課金の流れ

```
アカウント登録
  → お試し開始（80問 / 100MB・最長2年）

  ├─ いつでも → スターター ¥980
  │               → 期限解除・200問 / 100MB・永続

  ├─ 上限到達（お試し中）
  │     → スターター誘導（または スターター＋月額を同時 Checkout 可）
  │     → 新規追加ブロック・既存学習は継続

  ├─ スターター済みで上限到達
  │     → S / M / L へ誘導
  │     → 新規追加ブロック・既存学習は継続

  └─ 2年経過・スターター未購入
        → 通知 → 猶予 → ワークスペース削除
```

**ルール**

- 月額のみ（スターター未購入）は **不可**
- 月額の事前契約は **v1 では不可**（上限超過時のみ）
- 月額解約後は **スターター枠（200問 / 100MB）** に戻る（スターター購入権は維持）

### 3.4 ユーザー区分


| 区分            | 条件                               | 期限       | 削除対象   |
| ------------- | -------------------------------- | -------- | ------ |
| 九九・県庁利用者      | WS 外                             | なし       | いいえ    |
| 学習者           | `workspaceMembers`               | なし       | いいえ    |
| **お試しクリエイター** | スターター未購入                         | **最長2年** | **はい** |
| スターター済み       | `appPurchase.status == "active"` | なし       | いいえ    |
| 月額契約中         | `subscriptionStatus == "active"` | 契約に従う    | いいえ    |


**「無料ユーザー」＝ お試しクリエイター**（スターター未購入の WS オーナー）。

### 3.5 誘導と削除（①②③）

#### ① スターター誘導（¥980）


| タイミング                |
| -------------------- |
| 登録直後（ダッシュボード常時）      |
| 使用率 80%              |
| お試し残り 90日 / 30日 / 7日 |


#### ② 月額誘導（S / M / L）


| タイミング                      |
| -------------------------- |
| 問題数 or ストレージが現在プランの上限到達    |
| お試し中に到達 → まずスターター（＋必要なら月額） |


#### ③ 削除対象

**対象:** お試し満了（2年）かつスターター未購入（上限未満でも同様）


| 時点           | 動作                                       |
| ------------ | ---------------------------------------- |
| 満了 90日前      | スターター誘導（バナー・メール）                         |
| 満了 30日前      | 強い警告                                     |
| 満了日          | 新規作成・編集ブロック                              |
| 満了 + **60日** | **ワークスペース削除**（Firestore・Storage・メンバー紐づけ） |


- `users` アカウント自体は残す（再スターター可能）
- 削除前にオーナーへ最終通知
- 学習者は当該 WS の教材にアクセス不可になる（事前通知）

### 3.6 ユーザー向け説明（文案）

> **お試し（無料・2年）** … 80問・100MBまで教材づくりを試せます。  
> **スターター（¥980）** … 200問・100MBまで期限なく使えます。  
> **月額 S/M/L** … 問題や写真が増えたときの容量アップです。  
> お試し期間を過づてスターターに登録されない場合、データは削除されます（事前にお知らせします）。

## 4. 登場人物（ロール）

### 4.1 プラットフォーム管理者


| 項目   | 内容                                                |
| ---- | ------------------------------------------------- |
| 識別   | Firestore `admins/{uid}` が存在する Firebase Auth ユーザー |
| 権限   | 全ワークスペースの閲覧・サポート、公式コンテンツ、障害対応、課金例外処理              |
| ログイン | メール＋パスワード（現行 `/admin` と同系統）                       |


### 4.2 クリエイター


| 項目   | 内容                                                                          |
| ---- | --------------------------------------------------------------------------- |
| 識別   | `users/{uid}` に `role: "creator"`（または `workspaces` の `ownerId`）             |
| 権限   | 自分のワークスペース内のコンテンツ CRUD、画像アップロード、学習者招待・紐づけ、公開設定                              |
| 前提   | **お試し中** または **スターター済み**（`appPurchase.status == "active"`）。無償の九九・県庁の「作成」は不可 |
| ログイン | メール＋パスワード（必須）                                                               |


### 4.3 学習者


| 項目   | 内容                                                                           |
| ---- | ---------------------------------------------------------------------------- |
| 識別   | `users/{uid}` に `role: "learner"`、`workspaceMembers` で **1 人以上のワークスペースに紐づく** |
| 権限   | 紐づいたワークスペースの **許可された公開コンテンツ** を学習                                            |
| ログイン | **推奨: 任意（ハイブリッド）** — 詳細は [§7](#7-公開方式と学習者ログインの推奨)                            |

## 5. 認証（メールアドレス）

### 5.1 方式

- **Firebase Authentication**: メールアドレス＋パスワード
- サインアップ時: メール確認（推奨）、パスワードリセット

### 5.2 ユーザードキュメント（Firestore）

コレクション `users/{uid}`:

```typescript
{
  email: string;
  displayName?: string;
  role: "creator" | "learner";
  appPurchase?: {
    status: "none" | "pending" | "active" | "refunded";
    product: "starter";
    purchasedAt?: Timestamp;
    provider?: "stripe";
    paymentId?: string;
  };
  createdAt: Timestamp;
  updatedAt: Timestamp;
}
```

### 5.3 現行管理者との関係

- `admins/{uid}` はプラットフォーム管理者専用
- 同一 UID が管理者かつクリエイターになり得る

### 6.1 無償コンテンツ（ワークスペース外）


| コンテンツ | URL        | 保存                                |
| ----- | ---------- | --------------------------------- |

- お試し・スターター・サブスクの対象外

### 6.2 ワークスペース

```
workspaces/{workspaceId}
  ownerId: string
  name: string
  slug: string
  inviteCode: string
  planId: "trial" | "starter" | "s" | "m" | "l"
  accountPhase: "trial" | "starter" | "subscribed"
  trialEndsAt: string | null     // お試し終了日（ISO）。スターター購入後は null
  storageBytesUsed: number       // Functions のみ更新
  storageBytesLimit: number
  questionCount: number
  questionCountLimit: number
  subscriptionStatus: "none" | "active" | "past_due" | "canceled"
  appPurchaseStatus: string      // オーナー購入状態のコピー
  createdAt, updatedAt
```

**Storage パス**

```
workspaces/{workspaceId}/lesson-images/{contentId}/{filename}
```

ドキュメント ID: `trial` | `starter` | `s` | `m` | `l`

詳細は [billing-tiers-setup.md](./billing-tiers-setup.md)。

### 6.4 学習者紐づけ

`workspaceMembers/{workspaceId}_{learnerUid}` — 招待コードまたはメール招待。

### 6.5 学習進捗（Phase 1）

### 7.1 テナント付き URL

デフォルト `members`、必要に応じて `unlisted`。

## 8. 課金仕様（詳細）

### 8.1 状態遷移（クリエイター）

```
[未登録]
  → サインアップ + WS 作成
[trial / お試し]
  → 80問・100MB 内で作成（最長2年）
  → 任意のタイミングでスターター ¥980
[appPurchase.active / starter]
  → 200問・100MB 内で作成（期限なし）
  → 上限超過
[subscription active / s|m|l]
  → ティア枠内で継続
  → 解約後 starter 枠へ
[trial 満了 + 未購入]
  → 猶予後 WS 削除
```

### 8.2 問題数のカウント規則


| 含める                                 | 含めない                 |
| ----------------------------------- | -------------------- |
| `type: "quiz"` の `quiz.questions[]` | 九九・県庁                |
| 下書き `draft`                         | `status: "archived"` |


### 8.3 ストレージのカウント規則


| 含める             | 含めない             |
| --------------- | ---------------- |
| WS 内アップロード画像    | 外部 URL のみの画像     |
| `assets` 管理ファイル | `public/` 静的ファイル |


### 8.4 上限チェック（実装方針）

1. **クライアント**: 使用率表示、80% で警告
2. **Callable Function**: 問題追加・画像アップロード前に検証
3. **Storage**: 署名付き URL は Function 発行のみ（推奨）

### 8.5 超過・未契約時の挙動


| 状態               | 新規問題       | 新規画像       | 編集    | 既存の学習  |
| ---------------- | ---------- | ---------- | ----- | ------ |
| お試し・上限到達         | ×          | ×          | ×     | ○      |
| お試し・期限満了         | ×          | ×          | ×     | ○（猶予中） |
| スターター済・上限到達・月額なし | ×          | ×          | ○（枠内） | ○      |
| 月額契約中            | ○（ティア内）    | ○（ティア内）    | ○     | ○      |
| 月額 `past_due`    | ×          | ×          | —     | ○      |
| 月額解約後            | ○（スターター枠内） | ○（スターター枠内） | ○     | ○      |


### 8.6 決済連携（Stripe）

- **スターター**: Checkout `mode: payment`（`NEXT_PUBLIC_STRIPE_STARTER_PRICE_ID` または同等）
- **月額**: Checkout `mode: subscription`（`billingTiers/{s|m|l}.stripePriceId`）
- Webhook で `users.appPurchase` と `workspaces.planId` / 上限値 / `trialEndsAt` を更新

### 8.7 広告表示


| planId          | 学習画面の広告 |
| --------------- | ------- |
| `trial`         | 表示      |
| `starter`       | 非表示     |
| `s` / `m` / `l` | 非表示     |

- 書き込み: オーナー + 上限内（Callable 経由）
