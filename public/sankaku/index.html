いろいろな三角形の性質

三角形には、いろいろな性質があります。ここでは図を見ながら、ひとつずつまとめていきます。

1. 三角形の内角と外角

3つの頂点が A, B, C である三角形 ABC があります。 ㋐・㋑・㋒のように、三角形の内側にある角を、三角形の 内角 といいます。

辺 BC をのばしたときにできる、㋓のような角を 外角 といいます。外角は、頂点 C のそばで、辺 BC とその延長のあいだにできます。

2. スリッパの定理（外角の定理）

三角形の2つの内角の和は、隣り合わない外角の大きさと等しい、という性質があります。これを外角の定理といい、スリッパの定理とも呼ばれます。

㋐＋㋑＝㋓

この図では、頂点 A の内角 ㋐と、頂点 B の内角 ㋑を足すと、頂点 C の外角 ㋓と同じ大きさになります（㋒ は頂点 C の内角なので、式には入りません）。

3. さっ角と同位角

さっ角

さっ角（錯角）は、2本の平行線と、それを横切る直線が、平行線の内側でつくる、ねじれた位置にある角の組です。平行線では、さっ角の大きさは等しくなります。

同位角

同位角は、横切る直線の同じ側にあり、平行な2直線に対して同じ位置にある角の組です。平行線では、同位角の大きさも等しくなります。

4. 直角三角形と三角じょうぎ

三角じょうぎは、どちらも直角三角形です。くらべて、それぞれの角の大きさを確かめましょう。

45°の三角じょうぎは、直角・45°・45°の三角形です。30°・60°の三角じょうぎは、直角・60°・30°の三角形です。

30°・60°の三角じょうぎでは、直角をはさむ2辺のうちいちばん短い辺の長さは、もう1辺（斜辺ではない辺）の半分（2分の1）になります。つまり、斜辺ではないもう1辺の長さは、いちばん短い辺の2倍です。
